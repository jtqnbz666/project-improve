# 配置生成系统 - 架构原理详解

## 🎯 系统设计理念

### 核心价值
1. **策划友好**：Excel界面，无需编程知识
2. **类型安全**：强类型检查，避免运行时错误
3. **多语言支持**：同时生成C++和Python代码
4. **自动化**：CI/CD集成，减少人工干预
5. **可扩展**：模板化设计，易于支持新语言

## 🔍 核心组件详解

### 1. Excel解析器 (TypeParser)
```python
class TypeParser:
    @staticmethod
    def parse_value(value, type_str):
        # 根据类型字符串解析单元格值
        # 支持: int, float, string, vector, map, json
```

**工作原理：**
- 读取Excel的前3行（字段名、类型、描述）
- 使用正则表达式解析复杂类型（如`dict<string,int>`）
- 将字符串值转换为对应的Python对象

### 2. 类型系统
```
基础类型：int, float, string
容器类型：vector<T>, dict<K,V>, array<pair<T1,T2>>
特殊类型：json (自动解析JSON字符串)
```

### 3. 命名规范转换
```python
# 匈牙利命名法
def to_cpp_variable_name_with_type(field_name, field_type):
    type_prefix = {
        "int": "n",      # nId
        "string": "s",   # sName  
        "float": "f",    # fValue
        "vector": "v",   # vKeywords
        "map": "m"       # mStrToIntMap
    }
```

### 4. 模板引擎 (Jinja2)
```jinja2
struct S{{ class_name }} {
{% for field in fields %}
    {{ field.type | to_cpp_type }} {{ field.name | to_cpp_variable_name_with_type(field.type) }};
{% endfor %}
};
```

## 🔄 数据流转过程

### 阶段1: 数据读取
```
Excel文件 → openpyxl → Python字典
```

### 阶段2: 类型解析
```
"gold:100;diamond:10" → {"gold": 100, "diamond": 10}
"repeated string" → std::vector<std::string>
```

### 阶段3: 模板渲染
```
Python数据 + Jinja2模板 → 目标语言代码
```

### 阶段4: 文件分发
```
生成的代码 → 配置映射 → 目标项目目录
```

## 🎛️ 配置映射机制

```json
{
    "DemoConfig": {
        "py_targets": ["webservice/GeneratedConfigs"],
        "cpp_targets": ["service/sjgame/sjgame/configs"]
    }
}
```

**工作原理：**
- 根据配置名查找对应的Excel文件
- 生成代码后自动复制到指定目录
- 支持一份配置分发到多个目标

## 🚀 CI/CD集成原理

### GitLab Pipeline流程
```yaml
stages:
  - generate  # 生成配置文件
  - review    # 代码审查
  - deploy    # 部署到环境
```

### 触发条件
```yaml
rules:
  - changes:
      - config_tool/configs/*.xlsx
      - config_tool/generate.py
      - config_tool/templates/**/*
```

## 💡 设计模式

### 1. 模板方法模式
- 定义代码生成的骨架流程
- 具体的类型转换和格式化由子方法实现

### 2. 策略模式
- 不同的类型解析策略
- 不同的命名规范策略

### 3. 观察者模式
- CI/CD Pipeline监听文件变化
- 自动触发代码生成

## 🔧 扩展性设计

### 支持新语言
1. 创建新的模板文件
2. 添加类型转换过滤器
3. 更新配置映射

### 支持新数据类型
1. 扩展TypeParser
2. 添加类型转换规则
3. 更新模板

### 支持新的配置源
- 可以扩展支持JSON、YAML等格式
- 只需实现对应的解析器接口

这套系统的核心优势是**分离关注点**：策划专注配置内容，程序专注逻辑实现，系统自动处理中间的转换过程。
